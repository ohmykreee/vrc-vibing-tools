# Vibing Tool-sets for VRChat Project
一些为了 VRChat 改模借助 AI 写的一些小工具。使用 MIT 协议开源。
1. 不保证代码质量/功能健全
2. 不对把你项目弄崩负责
3. 没有义务提供使用指导

## 安装/使用方法
1. Clone 整个项目
2. 将工具代码复制到 `Assets/Editor` 下
3. （TODO）写一个 workflows 在线编译 UnityPackage 出来

## 工具简介
1. BlendShapeSync：最早的小工具，同步两个相同模型的 BlendShape 状态，基本上用不着。
2. Vpd2Amin：将 MMD 的 VPD 文件转换为单帧 Humanoid 可用的 Anim 文件。
3. 将多个姿势 Anim 文件合并为 [BUDDYWORKS Poses Extension](https://repo.buddyworks.wtf/) 可用的 PoseBank 格式。
